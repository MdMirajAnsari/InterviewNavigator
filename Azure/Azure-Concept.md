## Azure Function

* **Azure Function** is a **serverless compute service** by Microsoft Azure.
* It allows you to  **run small pieces of code (“functions”) without managing servers** .


Azure Functions run when  **triggered by an event** :

1. **HTTP Trigger** → Respond to HTTP requests
2. **Timer Trigger** → Run on schedule (like cron jobs)
3. **Blob Trigger** → Triggered when a file is uploaded to Azure Blob Storage
4. **Queue Trigger** → Triggered when a message is added to an Azure Storage Queue
5. **Event Grid / Service Bus Trigger** → Event-driven integrations
